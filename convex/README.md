# Convex Real-Time Sync Backend (100% Free Tier)

Zero-cost real-time reactive sync for HDRezka App across iPhone, iPad, and Mac.

## What It Syncs
- **Continue Watching State**: Pick up an episode on iPad exactly where you paused on iPhone with 1-second timestamp accuracy.
- **Watchlist & Bookmarks**: Instantly sync saved movies and shows.
- **User Preferences**: Sync preferred audio studios and playback quality.

## Quick 1-Minute Setup

1. In this directory, run:
   ```bash
   npx convex dev
   ```
2. Log in with your GitHub/Google account (Free plan).
3. Copy your Convex Deployment URL (e.g., `https://happy-otter-123.convex.cloud`).
4. Paste into **HDRezka App -> Settings -> Convex Real-Time Sync**.
